// ----------------------------------------------------------
// Building both imgviewer and physics_vfx
// ----------------------------------------------------------



First, enable the viewer in the top-level `CMakeLists.txt:46-53`:

```cmake
set(IMAGE_PROCESSING_BUILD_VIEWER ON CACHE BOOL "" FORCE)
```

Then configure and build both executables:

```bash
cmake -S . -B build
cmake --build build --target physics_vfx dpa_imgviewer --parallel
```

Run the renderer from the project root, then launch the viewer:

```bash
./build/physics_vfx
./build/DPA_ImageProcessing/dpa_imgviewer -image images/test_image.exr
```
 Build `dpa_imgviewer` once:

```bash
cmake -S . -B build
cmake --build build --target dpa_imgviewer --parallel
```
